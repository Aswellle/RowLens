# RowLens — 产品简报与核心决策

## 一句话定位

**RowLens 是一个以本地处理为默认、可审查清洗步骤的数据文件工作台：拖入 CSV/TSV/JSONL，在同一页面预览、搜索、筛选、清理并导出，不需要上传数据或部署后端。**

## 目标用户

1. 开发者：检查日志导出、API 响应、批量配置和测试数据。
2. 运营/分析人员：快速清理第三方系统导出的 CSV，不想为一次操作启动完整电子表格软件。
3. 注重隐私的用户：处理含有邮箱、客户编号、交易数据等敏感字段的本地文件。

## 用户任务

- “我想知道这个文件里有什么列、多少行，有没有坏行。”
- “我需要快速找到某个值、筛选记录、隐藏不关心的列。”
- “我想删除空行、修剪首尾空白、去重，但先看到会影响多少行。”
- “我需要导出清洗后的数据，但原始文件不能被意外改写。”
- “我不希望文件内容离开我的电脑，也不想安装大型软件。”

## 核心产品原则

1. **数据正确性优先于炫技**：默认所有字段按字符串保留，避免意外把 `00123` 转成 `123`，或重写日期/大数。
2. **操作可解释**：清洗规则有明确作用范围、影响计数、预览与撤销。
3. **本地优先**：用户选择的文件内容不上传、不遥测；应用不请求远程 AI/API。
4. **性能有边界**：worker 解析、IndexedDB 分批存储、虚拟化显示；有资源上限和可行动错误，不宣称无限文件大小。
5. **源文件只读**：只导出新文件，不原地覆盖。
6. **克制的 UI**：先突出当前文件、快速搜索、数据网格与清洗步骤，不做复杂数据分析 IDE。

## 产品差异化

本地 CSV 查看器、离线 HTML 数据浏览器和桌面大文件工具已经存在。RowLens 不能把“本地打开、排序和搜索”当成全部卖点。差异化是：

- 让每个清洗动作都成为可见、可调整的步骤；
- 展示“将影响 X 行 / X 列”的预检信息；
- 提供清洗前后对照和重置；
- 明确区分“导出当前筛选结果”与“导出全量数据”；
- 用零服务依赖和可审计行为减少用户对数据上传的担忧。

## MVP 范围

### 必须有

- CSV、TSV 和 NDJSON/JSONL 导入。
- 拖放与文件选择；文件名、大小、导入进度、取消。
- CSV/TSV 分隔符与首行表头选择；列名为空/重复时提供稳定显示名而不丢字段。
- JSONL 每行一个 JSON object；坏行计数和可下载错误报告。
- 表格预览、虚拟滚动、全局搜索、每列筛选、稳定排序、列显示/隐藏。
- 数据摘要：总行数、有效行数、列数、错误行数、文件格式。
- 清洗步骤：Trim whitespace、Remove empty rows、Remove duplicates（全行或指定键列）、选择导出列。
- 添加/删除/启停步骤、查看每一步估算影响、重置到原始数据视图。
- 导出 CSV；导出“当前筛选结果”或“全部记录”；电子表格安全导出与原始值导出明确区分。
- 错误状态、空状态、取消、存储空间不足与可恢复体验。
- 响应式布局、键盘可用、深浅色主题、基础可访问性。
- 单元测试、关键流程端到端测试、CI、英文主 README（可附中文文档）。

### 不做（首版明确排除）

- 云端上传、账户、同步、远程 API、AI 自动分析、遥测。
- XLSX / XLS、Parquet、数据库连接、SQL 控制台、图表和复杂统计。
- 多人协作、云端保存、登录、在线分享。
- 原地修改源文件、公式执行、执行导入文件中的代码。
- 任意格式无损往返保证。
- 未经基准验证的“GB 级文件秒开”承诺。

## 成功指标

- 新用户可在 60 秒内完成首次打开示例数据、搜索或筛选、导出。
- 数据处理前后符合用例中预期的行数、值和顺序，不发生静默数据丢失。
- 文件内容不经网络请求发送；自动化测试和 Network 面板验证均无业务数据外传路径。
- 目标基准数据上 UI 不因解析而长时间冻结；实际性能指标待测试后写入 README。
- 零阻断级可访问性问题；所有核心操作可使用键盘完成。
