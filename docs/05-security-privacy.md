# RowLens 安全、隐私与数据保留规范

## 1. 隐私承诺边界

允许的声明：

> RowLens 在浏览器本地处理导入的数据文件。文件内容不会被上传到 RowLens 服务器；应用不包含遥测或第三方数据分析。浏览器可能缓存应用静态资源，并且为了处理当前文件，RowLens 会将解析记录暂存在本地 IndexedDB 中。

不允许的声明：

- “绝对安全”“完全不产生网络请求”（静态托管页面加载时可能需要网络）。
- “关闭页面后数据一定立刻删除”（浏览器关闭/崩溃时异步清理未必成功）。
- “支持无限大小文件”或“任何浏览器都能稳定打开 GB 文件”。

## 2. 数据流与网络

- 禁止 API 服务端、账户、遥测、广告、远程 AI、远程字体、CDN 运行时脚本。
- 所有依赖打包进构建产物；应用加载后文件选择/解析/清洗/导出不应产生携带文件数据的网络请求。
- CI 可检查源码中不允许的 `fetch`/XHR/`sendBeacon` 使用，允许项必须有注释与 ADR（初期应无业务网络请求）。
- 不将文件名、字段名、记录内容、路径或错误行原文写入日志。

## 3. 本地存储

- IndexedDB 只保存当前处理所需数据和元信息。
- 退出/移除时清理当前 dataset；启动时清理过期和未完成 dataset；TTL 24 小时。
- 提供显眼的 `Clear local temporary data` 操作，并说明会清空本应用临时数据，不会删除用户源文件。
- 用户清除浏览器站点数据后应用应能正常恢复。
- 存储配额被拒或数据不可读时，安全失败并给出说明；不能部分导出并声称完整。

## 4. 导入输入安全

- 文件扩展名和 MIME 类型是提示，不是可信证明；文件内容可能恶意构造。
- CSV 解析交给维护中的 parser；处理异常长度、畸形引号、超大字段与大量列。
- JSONL 每行限制最大长度（初始 5 MiB，实际测试可调整）；限制列数与总 schema 大小以避免资源耗尽。
- 显示文件数据时必须使用 React 文本节点，不可用 `dangerouslySetInnerHTML`。
- 单元格内出现 HTML、脚本片段或 Markdown 时只展示文本；不自动渲染链接或执行代码。
- 文件名显示时转义控制字符、截断极长名称，禁止作为 HTML。

## 5. CSV Formula Injection

CSV 不是无害的“纯文本”导出：电子表格软件可能把以 `=`, `+`, `-`, `@` 等危险前缀开头的单元格解释成公式。

- 默认安全模式应根据最新 OWASP 指引检测可能公式前缀；测试 `=1+1`、`+cmd`、`-1+2`、`@SUM(...)`、前置空格/Tab/CR/LF 的组合。
- 安全模式在有风险的单元格前增加可见的文本保护前缀或使用经过验证的策略，并统计被修改单元格数。
- Raw 模式保留原始值，但在导出前明确提示风险；不能通过静默修改所谓“原始导出”来误导用户。
- 不得将某个方案宣称为对所有电子表格、所有区域设置都绝对安全。

## 6. 导出与 Object URL

- 不覆盖原始文件；输出文件用新文件名，默认 `-cleaned` 后缀。
- Object URL 在下载流程不再依赖后及时 revoke；管理 URL 生命周期防止内存泄漏。
- 大文件回退下载需受限；当无法使用文件写入流且结果超过安全预算时，拒绝生成并给出替代路径，而不是尝试分配无限内存。
- 文件名按安全策略清理路径分隔符、控制字符与危险扩展名。

## 7. 依赖与供应链

- 固定 lockfile；CI 中使用 `npm ci`。
- 对依赖许可证和维护状态做审查；禁止执行未经审计的安装脚本或引入不明 CDN。
- 生产依赖保持最少；每次添加依赖说明收益、替代方案和维护成本。
- 启用 Dependabot 或等效的依赖更新 PR 时，由测试确认升级不改变解析和导出行为。

## 8. 威胁模型

| 威胁 | 缓解方式 | 剩余限制 |
|---|---|---|
| 恶意超大文件导致卡死/OOM | 大小/行长/列数限制、Worker、chunk/backpressure、取消 | 浏览器自身内存和 IDB 配额因设备而异 |
| 公式注入导出 | 默认安全导出、风险预览、Raw 模式警告 | 各电子表格软件行为不完全一致 |
| 数据意外外传 | 无遥测/无业务 API、审查网络请求 | 静态站点资源本身可能从托管域下载 |
| 导入行作为 HTML 执行 | 文本渲染、不使用危险 HTML 注入 | 新功能必须持续遵守该约束 |
| 临时数据残留 | 移除清理、TTL 启动清理、清理按钮 | 浏览器异常关闭可能延迟清理 |
| 不正确解析造成静默丢数据 | 解析库、错误摘要、契约测试、源文件只读 | 某些编码/不规范文件需要人工检查 |

## 9. 发布前安全验收

- Network 面板确认数据导入后没有文件内容请求。
- 查找项目里所有 `fetch`、XHR、`sendBeacon`、`WebSocket` 和外部脚本引用，逐一解释。
- 导入含 `<script>`、`onerror=`、HTML、控制字符的值不执行。
- 导出公式注入 fixture，验证安全模式输出和 Raw 警示。
- 取消导入、制造配额错误、刷新页面中断导入，检查数据集状态与清理。
