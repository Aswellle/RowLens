# RowLens 发布验收清单

逐项勾选并附证据。不能仅以“看起来完成”作为通过。

## 安装与工程

- [ ] 在干净工作区按 README 指令安装，锁文件安装成功。
- [ ] `typecheck`、unit tests、production build 全部通过。
- [ ] CI 使用锁文件安装，不发生未声明依赖。
- [ ] 无未使用的大型依赖；无远程字体、CDN 脚本、遥测或文件上传接口。

## 导入

- [ ] CSV/TSV 能正确处理引用逗号、引号、跨行字段、BOM、CRLF/LF。
- [ ] JSONL 能处理 UTF-8 chunk 边界、CRLF、最后一行无换行、无效行继续解析。
- [ ] 重复/空列名不会覆盖数据；前导零与日期字符串保留。
- [ ] 导入有进度、可取消；快速换文件不会混淆结果。
- [ ] 超出大小/行长度/存储限额时安全失败并显示说明。
- [ ] 部分失败不被标记为完整成功。

## 查询与 UI

- [ ] 搜索、列过滤、稳定排序、清除条件、隐藏列工作正确。
- [ ] 虚拟化验证：DOM 中渲染行数与 viewport 相关而非总记录数。
- [ ] 零结果、警告、错误和空状态均有可操作下一步。
- [ ] 360px、768px、1280px、1440px viewport 布局通过。
- [ ] 仅用键盘完成核心路径；焦点环可见；对比度检查通过。

## 清洗与导出

- [ ] Trim 不改内部空格。
- [ ] Empty-row 删除行为符合选定列范围。
- [ ] Dedup 保留第一条，键列与全行模式正确，稳定排序成立。
- [ ] pipeline 启停/重置正确，原始 IndexedDB rows 未改变。
- [ ] Filtered vs All 导出范围有明确区分。
- [ ] CSV quoting 和 CRLF 正确；独立解析回读结果与预期一致。
- [ ] Spreadsheet-safe 与 Raw 模式有不同 UI 提示和测试。
- [ ] 大导出、取消、保存失败、Object URL 生命周期有测试。

## 隐私与安全

- [ ] 解析/清洗后 Network 面板未发现文件内容外传。
- [ ] XSS 样例只显示为文本。
- [ ] Formula injection fixtures 得到预期安全/原始导出行为。
- [ ] 移除 dataset、退出、过期 cleanup 与配额错误路径验证过。
- [ ] 文件名和错误文本不会被渲染成 HTML；敏感行不会写入 console。

## 发布质量

- [ ] README 不包含未经实测的性能承诺。
- [ ] README 明示支持格式、限制、隐私边界和 CSV 安全导出策略。
- [ ] 合成示例数据与截图不存在真实个人信息。
- [ ] LICENSE、CONTRIBUTING、CODE_OF_CONDUCT、SECURITY、CHANGELOG 齐全。
- [ ] 已知限制公开记录；无未解决 P0/P1。
- [ ] 远程发布、仓库创建、打 tag 等动作已获得维护者授权。
