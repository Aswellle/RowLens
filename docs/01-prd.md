# RowLens 产品需求文档（PRD）

## 1. 版本目标

本 PRD 定义 v0.1 MVP。任何超出此范围的功能必须先记录为后续版本，不得为了“看起来完整”而延迟数据正确性和导出安全。

## 2. 核心用户流程

1. 用户打开 RowLens，看到空状态及“拖入文件 / 选择文件 / 加载示例”。
2. 选择 CSV、TSV 或 JSONL/NDJSON 文件。
3. 应用做文件类型、大小、格式初检；显示导入进度和取消按钮。
4. 解析任务在 Worker 内运行，行按批次写入 IndexedDB；界面保持可操作。
5. 导入结束后显示行/列/错误摘要和数据网格。
6. 用户搜索、筛选、排序或隐藏列。
7. 用户添加清洗步骤，看到规则、作用范围和预计影响；执行后可查看结果或停用步骤。
8. 用户选定导出范围、格式与 CSV 安全模式。
9. 应用生成下载文件；原始文件不被改写。

## 3. 功能需求

### FR-01 文件输入

- 支持文件选择与拖放；拖放时阻止浏览器把文件直接导航打开。
- 依据扩展名、MIME（不可信）和内容特征综合判断；不得只相信扩展名。
- MVP 支持 `.csv`、`.tsv`、`.jsonl`、`.ndjson`。对不支持格式显示明确原因，不做静默猜测。
- 首版目标上限为配置项，不在代码中写散落常数。初始 `MAX_FILE_BYTES` 建议 100 MiB（待实机验证后调整）；超过时可拒绝导入并说明原因，不允许浏览器直接卡死。
- 导入任务支持取消；取消后数据集不得被当成完整文件展示。

### FR-02 CSV / TSV

- 使用 Papa Parse 处理引用符、分隔符、转义、CRLF/LF 和包含换行的引用字段；禁止用 `split(',')` 解析 CSV。
- CSV 默认自动猜测 delimiter，但向用户提供检测结果和修改入口。TSV 默认 tab。
- 首行表头可开关。无表头时生成 `Column 1`、`Column 2` 等显示名，并保留原始字段序号。
- 空列名使用稳定占位名；重复列名不得合并或覆盖，内部列 ID 必须唯一。
- 默认 `dynamicTyping: false`，保留原始字符串。
- 每行字段数与预期列数不一致时记录解析问题；如能安全保留，不得静默截断字段。错误摘要显示数量和例子行号，不展示大量原始内容。

### FR-03 JSONL / NDJSON

- 每个非空行独立解析为 JSON object；首版不接受顶层数组作为 JSONL 记录。
- 顶层 key 形成列；嵌套 object/array 以 JSON 字符串形式显示，不能静默丢弃。
- 后续记录新增 key 时，向 schema 添加列，早期记录该列显示为空。
- 错误行不中断整个导入；保存行号、错误类别，提供“下载错误报告”。错误报告是否包含原始行由用户明确选择，默认只包含行号和错误类别。
- 解析过程需处理 CRLF、最后一行无换行、UTF-8 多字节字符跨 chunk 的情况。

### FR-04 数据网格

- 固定行高的虚拟化网格；只渲染视口附近的行。
- 表头吸顶；允许横向滚动；列宽有最小值和截断省略号，完整单元格文本可通过复制或辅助提示获取。
- 每列显示稳定名称；排序状态通过按钮和 `aria-sort` 表达。
- 全局搜索默认为字面子串、不区分大小写；不把输入解释为正则表达式。
- 每列筛选默认为字面子串；空筛选表示不限制该列。
- 排序必须稳定：相等值按原始 rowIndex 保序；默认字符串排序，不自动把日期、货币或前导零转型。
- 搜索、过滤、排序操作显示结果行数，并保留清除筛选入口。
- 当筛选结果为 0 行，显示空结果状态和一键清除条件。

### FR-05 清洗步骤管线

清洗步骤应保存为可序列化配置，而不是直接破坏原始存储数据。v0.1 包含：

1. **Trim whitespace**：对全部列或选定列移除字符串首尾空白；不得删除内部空白。
2. **Remove empty rows**：移除所有选定字段（默认全字段）为空白的行；空字符串和纯空白如何处理必须有测试。
3. **Remove duplicates**：全行去重或指定键列；保留第一次出现的记录，保证稳定顺序；比较规则明确为 trim 后还是原始值，由用户选项控制，默认基于当前步骤前的值、精确比较。
4. **Select columns**：指定导出列并调整导出顺序；预览中隐藏列不等于删除源字段。

约束：

- 每个步骤具备 `id`、类型、参数、enabled 和显示名称。
- 步骤顺序影响结果；允许启用/停用、删除、清空全部步骤。
- 修改规则后通过后台重算结果；新结果生成前保留旧 UI 状态并显示忙碌标记。
- 清洗步骤影响行数的计算不能静默近似。若只能逐行扫描，应显示正在计算进度。
- v0.1 暂不提供任意单元格编辑、正则替换和跨列公式。

### FR-06 导出

- 输出 CSV；UTF-8、CRLF、双引号转义规则固定并写入文档。
- 明确区分：`Export filtered rows` 与 `Export all rows`。
- 明确区分当前视图列与导出选择列。
- 默认选择 **Spreadsheet-safe CSV**。疑似公式字段（首个非空白/控制字符后为 `=`, `+`, `-`, `@` 等风险前缀）应用防护策略；提示某些值会被前缀转义，导出文件与原始值不同。
- 提供 **Raw CSV** 选项，但需通过简短提示说明：在 Excel/LibreOffice 等电子表格软件打开时，某些字段可能被解释为公式。不得声称任何单一转义策略对所有软件绝对安全。
- 导出用流式/chunk 生成方式，避免同时保有原文、整份 JSON 和整份 CSV 三份大对象。
- 支持环境中可用的文件保存流 API；不支持时回退下载 Blob。回退方式必须有更严格的大小门槛和错误提示。
- 导出失败时保留当前 dataset 与清洗规则，不显示虚假的“已保存”。

### FR-07 本地存储与清理

- 原始行数据存储在 IndexedDB，以 datasetId + rowIndex 为键分批写入；不把完整数据集存入 React state。
- 数据集元信息包含创建时间、导入状态、格式、字节数、行数、列 schema、解析错误摘要与版本。
- 默认不提供跨会话历史/永久收藏。用户关闭或移除数据集时，应用尽力清除对应 IndexedDB 记录；应用启动时清理超过 TTL 的残留/未完成数据集。
- UI 说明浏览器本地存储特性：异常关闭或浏览器无法完成清理时，临时记录可能保留至下一次启动清理；提供“清除本地临时数据”。
- IndexedDB 配额不足时中止导入、清理部分数据、显示可操作说明；不得丢失或覆盖用户源文件。

## 4. 非功能需求

- TypeScript strict；UI 主线程不承担长时间全文件解析、去重或全量导出计算。
- 有明确的 Worker 消息协议、任务 ID、取消行为、进度和异常状态。
- 所有用户内容作为文本渲染，不使用不可信 HTML。
- 不发送数据文件内容、字段值、文件名或使用量事件到远端。
- 不引入账户、服务端、遥测、远程字体或运行时 CDN。
- 基础浏览器目标：当前稳定版 Chrome / Edge / Firefox / Safari；实际支持矩阵由 CI 与手动测试证据确定。不能保证所有 API 在每个浏览器都相同。
- UI 适配 360px 到大屏；数据表在窄屏允许横向滚动，不把大量列强行压缩到不可读。

## 5. v0.2 候选（不在 MVP 中默认实现）

- JSON 数组 / 对象导入。
- TSV/JSONL 导出、列统计、数据类型提示。
- 按导出结果生成可复现清洗配方。
- PWA 离线缓存（单独审查缓存与敏感数据边界后再做）。
- 超大文件只读模式或 file-backed index。必须先有测量数据再决定技术方案。
